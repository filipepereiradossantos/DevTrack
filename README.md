# DevTrack — Gerenciador de Tarefas

O **DevTrack** é um projeto web desenvolvido para praticar e aplicar conhecimentos de desenvolvimento front-end, com foco na organização de tarefas por meio de uma interface simples e intuitiva.

🔗 **Acesse o projeto:** [DevTrack — GitHub Pages](https://filipepereiradossantos.github.io/DevTrack/)

## 📌 Sobre o projeto

O DevTrack permite organizar tarefas em uma interface própria, acompanhando informações como prioridade, vencimento e situação de conclusão.

O projeto está sendo desenvolvido como parte da minha evolução prática em desenvolvimento web.

## ✨ Funcionalidades

- Cadastro de tarefas.
- Definição de prioridade: alta, média ou baixa.
- Informação de vencimento das tarefas.
- Visualização da quantidade de tarefas cadastradas.
- Acompanhamento de tarefas pendentes e concluídas.
- Páginas de início, tarefas e progresso.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas.
- **CSS3** — estilização e organização visual.
- **JavaScript** — lógica e interatividade.
